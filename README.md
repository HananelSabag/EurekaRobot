# EurekaRobot

אפליקציה משלנו לשואב השוטף Eureka NER 450 (מודול Midea, סוג B8, SN8 `320VR900`), במקום האפליקציה הרשמית.

## מה עובד (אוקטובר 2026)

- **ברשת הביתית:** חיבור ישיר לרובוט ב-TCP 6444 (פרוטוקול Midea V3), עם הספרייה `midea-local`. קריאת מצב, אחוז סוללה מדויק, תקלות, התחלה, עצירה וחזרה לעמדה.
- **דרך הענן של Midea (MSmartHome):** הערוץ `transparent/send` מעביר לרובוט את אותן פקודות. נבדק: מצב, התחלה וחזרה לעמדה. ערוץ ה-`lua/control` מחזיר OK אבל לא מזיז את הדגם הזה.
- **השרת (`server/`):** aiohttp. מחזיק את החיבור לרובוט, שומר היסטוריה ב-SQLite ומגיש את אפליקציית הווב (`web/`).

## מה למדנו על הדגם הזה

- מצב "כל הבית" הוא `arc` (0x02). את `auto` (0x08) הרובוט דוחה בלי הודעה.
- פקודת החזרה לעמדה עובדת כמתג: אם שולחים אותה כשהרובוט כבר בדרך הביתה, הוא עוצר. לכן שולחים אותה רק כשהוא לא בדרך.
- הסוללה מראה כ-50% בעמדה ו-20% מחוץ לה, בגלל מתח הטעינה.
- לחשבון יש מגבלה על מספר הכניסות הפעילות (שגיאה 65027). לכן תמיד מתחברים עם אותו device id.
- אין לו לייזר. הוא לא יודע איפה הוא נמצא, ולכן אי אפשר לשלוח אותו לחדר.

## הרצה

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m tools.get_key       # פעם אחת: מפתח מקומי מחשבון MSmartHome
.venv\Scripts\python -m tools.cloud_login   # פעם אחת: החשבון נשמר ב-Windows Credential Manager
.venv\Scripts\python -m server --host 0.0.0.0
```

הקבצים שב-`data/` (המפתח של הרובוט וההיסטוריה) נשארים מחוץ ל-git.

APK שמדבר עם הרובוט ישירות: ברשת הביתית כשנמצאים בבית, ודרך הענן מחוץ לבית. בלי שרת.
